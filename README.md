公開サイト: https://kitchen.okayu-llc.jp/
案件管理: https://kitchen.okayu-llc.jp/cm/
ローカル確認: http://10.100.10.10:8234

Node.js標準ライブラリ + HTML/CSS/JavaScript。新しいnpm依存はありません。

既存の淡い色、余白、明朝見出し、青緑の器のトップ写真とレスポンシブ表示を維持。利用場面、4つの強み、ユーザー提供のプロフィール、料金カード、実績写真、FAQ、相談フォームを追加。

## 編集箇所

`site.config.cjs` に電話、メールアドレス、料金、FAQ、実際のご依頼例を集約。

- `phone`: **未定・空欄**。正式な番号を設定するとトップ、問い合わせ欄、スマホ固定欄が `tel:` リンクになります。未設定時は「番号掲載準備中・フォームをご利用ください」と表示。
- `contactEmail`: **livekitchen.co@gmail.com**。直接メールリンク、管理者向けフォーム通知、お客様向け自動返信の返信先。後から `site.config.cjs` で変更可能。
- `prices`: 確定済みの料金。カジュアル／プレミアム等の区分を追加する場合もここにカードを追加。
- `faq`: 最少人数、地域、会場設備、書類、キャンセル等の正確な条件が決まったら更新。
- `examples`: 現在空配列。実データを追加すると「実際のご依頼例」カードを自動表示。`title / people / scope / total / note`。ダミー料金は表示しない。

設定変更後: `sudo systemctl restart italian-school.service`
本文・フォーム構造: `index.html`。外観: `style.css`。写真操作・送信UI: `script.js`。
HTML中の `{{...}}` はサーバーが設定から安全に描画します。ファイルを直接開く方式には対応していません。

## 問い合わせの受付と確認（稼働中）

同一サイトの `POST /api/inquiries` にJSON送信。検証後、非公開ディレクトリへ原子的に保存できた場合だけ受付番号を返します。電話連絡希望の場合は電話番号が必須で、任意の「電話連絡可能な時間」も保存・通知・連携対象になります。

保存場所: `/var/lib/italian-school/inquiries/<内部ID>.json`（受付番号とは別。管理コマンドは受付番号で検索可能）
フォルダ0700、ファイル0600、所有者www-data。URLでは公開されません。

管理者用コマンド（サーバー上で実行）:

```sh
sudo -u www-data node /srv/italian-school/inbox.cjs list
sudo -u www-data node /srv/italian-school/inbox.cjs show 受付番号
sudo -u www-data node /srv/italian-school/inbox.cjs reviewed 受付番号
```

一覧は受付番号・日時・状態・サービスのみ。詳細表示に氏名や連絡先が含まれます。問い合わせに対応する運営担当者が定期的に確認してください。不要になった個人情報の保管期間・削除は運営方針に従って管理してください。

## メール通知（送信環境の設定待ち）

**宛先は設定済みですが、自動メール通知はまだ有効ではありません。** 現状のホストではPostfixが停止、relayhostは `[]:25` の未設定状態です。既存ホスト全体のメール設定は変更していません。

メール送信は共通の `/cm/` 案件管理システムへ一本化しています。ホームページは問い合わせを保存・連携するだけで、SMTP設定を持ちません。`/cm/`が案件登録後に、該当テナントのオーナーへ概要通知、お客様へ受付確認を通知キューへ登録します。ホームページ側の `notify.cjs` は旧構成との互換用に残していますが、送信は常に無効です。

有効化には:
1. `/cm/`管理システムの `.env` にSMTPリレー、認証情報、`MAIL_FROM`、`MAIL_ENABLED=true`を設定する。認証情報はリポジトリに保存しない。
2. `livekitchen-system-notify.timer`を有効にし、`send_notifications`のログと送信先の受信結果を確認する。

`livekitchen-system-notify.timer` は毎分確認する設定です。SMTP未設定時は通知をDBキューに保持します。設定後は未通知分も処理し、失敗時は再試行します。通知状態は`/cm/`側のDBでテナント単位に管理します。

通知停止: `sudo systemctl stop livekitchen-system-notify.timer`

## /cm/ 案件システム連携

`system-sync.cjs` は保存済み問い合わせを共通のマルチテナント案件システムへ送るためのブリッジです。各ホームページはシングルテナントとして独立し、`CASE_SYSTEM_API_URL` は共通API、`CASE_SYSTEM_TENANT_SLUG` とサイトごとの `CASE_SYSTEM_API_KEY` で受け入れ先テナントを指定します。APIキーはブラウザへ出さず、root所有のEnvironmentFileにだけ置いてください。中央APIはAPIキーとテナント識別子の組み合わせを検証します。設定例は `.env.example` と `mail.env.example` にコメント付きで記載しています。連携データには受付番号、氏名、連絡先、電話連絡可能な時間、希望日、開催希望時間、場所、人数、予算、サービス、相談内容などが含まれます。

## 安全性・動作

サーバー側の型・文字数・日付・連絡先検証、本人同意、同一オリジン制限、署名付きCSRFトークンとHttpOnly/SameSite Cookie、非表示の迷惑投稿対策欄、短時間連投制限、32KB制限、タイムアウト、再送時の重複防止を実装。個人情報をアプリログへ出力しません。

送信失敗時は入力を保持。成功時はフォームをリセットし受付番号を表示。電話連絡を希望した場合のみ電話番号必須。希望日・人数等は未定のまま送信可能。

ギャラリーは6枚＋「もっと見る」5枚。拡大後の前後ボタン、左右キー、スワイプ、Esc、フォーカス復帰を維持。

## 受付番号
新規受付の表示番号は日本時間の `YYYYMMDD` ＋日別連番（01始まり）。例: `2026091501`、`2026091502`。日付が変わると01へ戻ります。100件目以降は3桁以上へ拡張し、受付を止めません。

番号予約は非公開の `/var/lib/italian-school/receipt-numbers/` に永続保存。内部IDと再送防止の仕組みは維持し、再送時は元の番号を返します。フォームの完了表示・通知メールの件名/本文・管理一覧を新番号に統一。過去の旧形式番号はそのまま有効です。番号予約ファイルを消すと過去番号の再利用につながるため、問い合わせ本文とは別に保持してください。

追加検証: 100件の同時受付、JST日付境界、再起動・日付をまたぐ再送、保存失敗からの回復、既存旧形式データとの互換性。
